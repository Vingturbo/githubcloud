# GHCD WIKI

> 该软件仍在开发中，尚未完成，WIKI 的编写，有为了指导开发的意思

## 简介

GHCD，全称 GayHub Cloud Disk ，主旨是利用 GitHub 仓库的 Releases 来存储文件，他的核心特征包括，高安全性且快速的文件加密，文件分享，文件完整性校验，几乎无上限的单文件体积，不受限于 Releases 的单文件 2GiB 限制，高可用性，配置丰富灵活、易于上手和使用，易于迁移，多预设管理，多用户互相隔离，支持高级的参数语法，和极具特色的命令语法
