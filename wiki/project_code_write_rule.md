# 项目代码编写规范

## 前言

这个文件的编写目的是为了规范代码风格和注意事项，避免编写低效或冗余的代码

## 构建标准

- 本项目使用 CMake 构建，你可以使用 C++20 的语法和关键字来编写程序
- 对于 Linux，使用 GCC 进行程序生成，同时在最新 Linux 内核和 glibc 下通过测试
- 对于 Windows，使用 MinGW GCC 进行程序生成，同时在 Windows10 x86_64 的情况下通过测试
- 对于 MacOS，使用 Clang 进行程序生成，同时在同一平台上通过测试，应当测试不同版本和处理器架构

## 代码要求

- 只能使用 C++20 的语法和关键字进行代码编写
- 不能使用诸如 **`#include <bits/stdc++.h>`、内联汇编、扩展支持的预处理** 等编译器特定扩展
- 尽量减少平台特异的宏，确保编写的代码最大程度上跨平台
- 尽确保程序在正常使用的情况下不出现未定义行为
- 缩进统一为4个空格
- 确保缩进正确，代码干净
- 对于一个与其他代码希望稍做区分的代码部分，可以使用 `do {} while(0);` 包裹，同时附带注释
- 使用逻辑最为清晰和简洁的代码
- 不要进行滥用诸如 类、模板、TMP 等会导致代码混乱且难以维护的行为
- 代码的每个部分作用明确，且正确的分为多个文件编写专门的，可复用的代码

## 代码思想

- 只假设用户会做出正确的行为，并且据此对代码逻辑进行优化，但是诸如网络连接超时等用户完全不可控因素，要确保正确处理和通知
- 代码是最好的注释，但也别给我不写注释。
- 建议使用 **Visual Studio Code** 进行代码编写，当然，如果你能配置好 vim 的插件，那也是没有问题的，毕竟 Electron 框架着实太重了
- 确保代码编译后尽可能的轻量，且对于**C++标准**之外的事务尽可能减少依赖（比如代码中明确的系统调用）
- 不要过多的引入外部库，尤其是为了那些极为简单的功能以至于能够轻易实现的功能
- 使用的外部库应当同样是跨平台性极高
- 摒弃过于庞大的外部库，而使用专精于需要方面的轻量库
